# Where to check the license
I do not have a single unified license for all my programs. The licenses vary.

When distributing a program on GitHub, the source code will contain a LICENSE file, which contains the license text.

## Common licenses I use and their summaries

### GPL-3.0
You can:
- Share the program
- Modify it
- Use it commercially

You can't:
- Change the license
- Demand compensation for potential damages caused by the program

You have to:
- Disclose where you got the program from
- State your changes to it
- Include this license and copyright statement of my authorship

https://www.gnu.org/licenses/gpl-3.0.en.html

### The Unlicense
The program and it's source code is released to the public domain, which means I surrender all my copyright rights to it.
You can do whatever the heck you want with it.

https://unlicense.org/

### None
If I don't provide the source code of a program you should treat it by default as **all right reserved**, unless there's a license that says otherwise.

You may contact me to provide a proper license to avoid confusion.
